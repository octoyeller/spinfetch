# Options

Animation:
- Run animation until closed
- Run animation for a duration
- Display a single frame
- Custom frame update interval
- Crop system info or frame

System info:
- [x] username
- [x] hostname
- [x] OS
- [x] system/kernel version
- [ ] uptime
- [ ] display
- [ ] cpu
- [ ] gpu
- [ ] ram
- [ ] disks
- [ ] ip
- [ ] shell
- [ ] theme
- [ ] desktop environment
- [ ] battery

Additional:
- Custom text
- Scroll text
- Execution time
- Favourite app or thing
- Random message



# The way

Fetch os info
Load frames
Crop
Display
Animate



# Arguments
v - version
h - help
u - update file
a - add file
s - scan files
d - duration of animation
i - interval of change
f - use frame other than set in config

# Options

- Run animation until closed
- Run animation for a duration
- Display a single frame
- Custom frame update interval
- Crop system info or frame

System info:
- [x] username

- [x] OS

- [x] shell
- [ ] theme
- [ ] desktop environment
- [x] battery
- [ ] no aliases
- [ ] terminal

Additional:
- Custom text
- Scroll text
- Execution time
- Favourite app or thing
- Random message



# The way

Fetch os info
Load frames
Crop
Display
Animate



# Arguments
v - version
h - help
u - update file
a - add file
s - scan files
d - duration of animation
i - interval of change
f - use frame other than set in config
